## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：同じ質問（uv run python -m app.ask）を4回実行した　1回目は「AIE2026についてのデータはない」と断ったうえで、「AI活用スキルの3段階」「基礎・応用・発展の課題レベル」「ルールベース・機械学習・ディープラーニング」の3通りを推測として挙げた　2〜4回目は「分からない」とは言わず、「一般的には」と前置きして、レベル1（基礎：穴埋めや写経）、レベル2（応用：自分で実装）、レベル3（発展・挑戦：高難度）という3段階を説明した。「まずレベル1から順に進めるのが一般的」といった助言も付いていた
- 用語集の正しい意味と比べて気づいたこと：モデルの回答は、名前（基礎・応用・発展）や中身（基礎→自分で実装→高度な課題）が偶然かなり近い一方で、「どれか1つで完了」「採点しない」という講座固有の肝心な点はどの回答にもなかった。逆に「レベル1から順に」と、実際のルールとは違う助言をしていた
同じ質問でも実行ごとに答えが変わった。また、知らないと認めたのは1回だけで、残りは一般論を講座の説明のように自信ありげに述べていた。もっともらしいが確かめようのない答えになっていた
- 表示できたトークン数（入力 / 出力）：入力 21 / 出力 704

## 宿題

- 取り組んだレベル：実装
- 使ったモデル：gemini-3.5-flash-lite（既定）
- やったこと：
  - `app/ask.py` に `--chat` オプションを追加し、会話履歴を保ったまま続けて質問できるようにした
  - `client.chats.create()` でチャットを作り、`chat.send_message()` で質問する。チャットが過去の質問と回答を履歴として持ち、毎回それを含めてモデルに送る
  - `exit` / `quit` / `終了` で終了。APIエラー（レート制限など）が出ても会話を続けられるようにした
  - 応答ごとに、入力・出力トークン数、応答時間、履歴のメッセージ数を表示するようにした
  - Copilot ではなく Claude に手伝ってもらってコードを書き、自分で実行して動作を確かめた
- 結果：uv run python -m app.ask --chat で次のように3回続けて質問した
回	自分の発言	　　　　　　　　　　　　　　　　　モデルの応答	　　　　　　　入力	出力	履歴
1	私の名前は渋谷です。数学を教えています。	あいさつと、どの分野を教えているかの質問　12	68	2

- 気づき・疑問：入力トークン数が 12 → 87 → 116 と増えた。2回目の入力 87 は「1回目の入力 12 ＋ 1回目の出力 68 ＋ 新しい質問 約7」、3回目の 116 は「87 ＋ 2回目の出力 21 ＋ 新しい質問 約8」とほぼ一致する。モデル自身が覚えているのではなく、毎回それまでの会話をまるごと送り直していることが数字から分かった　そのため、長い回答が続くと入力トークンが急に増える。長い会話では料金、無料枠のレート制限、コンテキストウィンドウの上限に効いてきそう。古い履歴を要約したり捨てたりする工夫が必要になるのではないか
